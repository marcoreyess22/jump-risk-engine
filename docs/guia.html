El pipeline

La idea central es que un solo generador de escenarios alimenta dos consumidores distintos. Los mismos futuros simulados sirven para decidir cómo repartir el capital y para medir cuánto se puede perder con ese reparto. Eso es lo que hace que la comparación entre modelos sea limpia: nadie tiene información que otro no tenga.

La pieza que lo hace extensible es el registro de modelos. Las diez especificaciones de VaR comparten una firma única y viven en un diccionario; el bucle de backtest itera sobre él sin conocer ninguna por nombre. Añadir un modelo es escribir una función y una línea más, sin tocar nada del motor.

modelo(rets, w, nivel, rng) → (VaR, ES)

El modelo

El precio no se mueve solo por difusión continua: de vez en cuando salta. La difusión con saltos de Merton suma las dos cosas sobre el retorno logarítmico diario:

X = m + σ·Z + Σi=1..N Yi con N ~ Poisson(λ), Yi ~ N(μJ, σJ²)

La parte gaussiana (σ·Z) es el ruido de todos los días. La suma de Poisson es el salto: la mayoría de los días N = 0 y no pasa nada, pero cuando ocurre añade un choque de magnitud propia. Eso es lo que produce colas gordas — y los datos las tienen: la kurtosis de exceso de los ocho activos va de 3.2 a 16.1, cuando una normal valdría 0.

Calibración sin optimizador

Los cumulantes de este proceso tienen forma cerrada, así que en vez de una máxima verosimilitud frágil se igualan directamente a los momentos muestrales:

κ₂ = σ² + λ(μJ² + σJ²) κ₃ = λ(μJ³ + 3μJσJ²) κ₄ = λ(μJ⁴ + 6μJ²σJ² + 3σJ⁴)
Decisión de modelado declarada

Son cinco parámetros contra cuatro momentos: λ no queda identificada. Distintos λ ajustan los mismos momentos igual de bien. Se fija en 0.05/día (12.6 saltos al año) y se reporta la sensibilidad con merton.sensibilidad_lambda(). Cerrarla exigiría el sexto cumulante muestral, que es ruido puro.

El salto sistémico

Si cada activo salta por su cuenta, los choques se promedian entre los ocho y la cola de la cartera vuelve a parecer normal — medido: ES/VaR de 1.159 con saltos independientes contra 1.162 del gaussiano. Las colas idiosincrásicas se diversifican.

La solución es un único proceso de Poisson compartido por todos los activos. Y sale gratis por un detalle de identificación: como λ es la misma en todos, compartir la cuenta no altera ninguna marginal. Cada activo conserva su calibración exacta y solo cambia cómo se acoplan. La correlación SPY–QQQ en el peor 1% de días pasa de −0.02 a +0.74.

Cómo correrlo

Cada módulo es ejecutable por sí solo y muestra su propia salida. Empieza por los rápidos para ver el motor funcionando antes de lanzar el backtest completo.

# instalación, una vez
pip install -r requirements.txt

# módulos rápidos — corre estos primero
python -m src.data       0.3 s   perfil de los 8 activos
python -m src.merton     0.4 s   calibración + sensibilidad a λ
python -m src.optimize   1.0 s   pesos de las 3 carteras
python -m src.risk       0.6 s   los 10 modelos sobre una ventana

# los pesados
python tests/test_core.py ~4 min  21 checks de validación
python -m src.backtest    ~8 min  walk-forward, escribe walkforward.csv

# requieren que backtest haya corrido antes
python -m src.basel      0.8 s   semáforo de capital y ES
python -m src.plots              las 6 figuras a figures/
python -m src.diario --sembrar corrida diaria con estado
Orden importa

basel y plots leen data/walkforward.csv, que produce backtest. Si los corres antes, fallan por archivo inexistente. Todo lo demás es independiente.

Cómo leer la salida

La tabla de veredictos

Es lo que produce src.backtest. Una fila por par cartera-modelo:

    cartera         modelo  exc  esperadas  razon   Kupiec    Indep
    min_var         normal   81      39.20   2.06 REPRUEBA REPRUEBA
    min_var      mc_merton   38      39.20   0.97     pasa REPRUEBA
 igual_peso           ewma   84      39.20   2.14 REPRUEBA     pasa

razon es excepciones observadas sobre esperadas. 1.0 es calibración perfecta; por encima el modelo subestima el riesgo, por debajo lo sobreestima.

Kupiec juzga la frecuencia. Indep juzga si las excepciones se apelmazan. Un modelo puede acertar cuántas veces falla al año y fallar todas en la misma semana — esa tercera línea es el único caso de 40 que pasa independencia, y lo hace reprobando la frecuencia.

Los dos ejes, y por qué ninguno los acierta ambos

ModeloFrecuenciaPersistencia π₁₁/π₀₁Lectura
ewma2.04 ✗3.6 ✓Sabe cuándo, no cuánto
mc_merton0.96 ✓20.4 ✗Sabe cuánto, no cuándo
fhs1.22 ✓7.5 ✓Lo único decente en ambos

La persistencia es cuánto se multiplica la probabilidad de excepción justo después de una excepción. 1.0 sería no agrupamiento. Ninguno llega ni cerca, pero condicionar por volatilidad la baja de 20 a 3.6.

El resultado incómodo

Proxy de capital = multiplicador × VaR medio — una vara de comparación, no una cifra regulatoria. El modelo que reprueba las cuatro pruebas cuesta 18.4% menos capital que el mejor calibrado. El multiplicador castiga como máximo +33%, y subestimar el VaR ahorra ~20% directo. Con el doble de la tasa de excepciones un modelo promedia 5.2 por ventana de 250 días — apenas la primera banda amarilla. El semáforo tiene poca potencia en esa ventana.

Para añadir una cartera, el patrón es idéntico con el diccionario CARTERAS de backtest.py: una función (ventana, rng) → pesos y su entrada.

Antes de confiar en tu modelo

Corre python tests/test_core.py. El check del día 11 recorre el registro completo y verifica VaR positivo, ES ≥ VaR y monotonía en el nivel de confianza. Un error de signo — el fallo más común al añadir especificaciones — salta ahí y no en el backtest de ocho minutos.
